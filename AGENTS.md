# EduTrace agent instructions

Use `EduTrace help` and `EduTrace status` before running research. Never assume `ask` is generative AI. Ask before running commands that add or expose notes. Do not include private data, keys, or decrypted results in prompts to cloud models without explicit informed permission. Never upload or publish anything from private storage. Preserve existing data and do not reset keys. For existing T14 data set `EDUTRACE_PRIVATE_DIR=/var/lib/edutrace-private`. Do not publish the local `private-assets/` screenshot without inspection and approval.
